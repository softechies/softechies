## Softechies Solutions

Software house in Karachi, building software for clients worldwide since 2012.

**What we build**
- **.NET & Windows:** Windows services, printer and device integrations (IPP, Print Support Apps, ESC/POS receipt printers), desktop tools, industrial protocols (Modbus)
- **Web & SaaS:** multi tenant SaaS on Next.js and Supabase, client portals, dashboards, licensing and billing
- **Integrations:** payments (JazzCash, Easypaisa), FBR POS invoicing, WhatsApp Cloud API, courier APIs, CAD/DXF processing, automation

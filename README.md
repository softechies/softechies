## Softechies Solutions

Software house in Karachi, building software for clients worldwide since 2012.

**What we build**
- **.NET & Windows:** Windows services, printer and device integrations (IPP, Print Support Apps), desktop tools, industrial protocols (Modbus)
- **Web & SaaS:** multi tenant SaaS on Next.js and Supabase, client portals, dashboards, licensing and billing
- **Integrations:** courier and payment APIs, CAD/DXF processing, automation

**Open source**

| Project | What it does |
|---|---|
| [dotnet-windows-service-starter](https://github.com/softechies/dotnet-windows-service-starter) | .NET 8 Windows Service template with logging, crash recovery and install scripts |
| [ipp-test-client](https://github.com/softechies/ipp-test-client) | Check printer status and send test prints over IPP |
| [modbus-tcp-simulator](https://github.com/softechies/modbus-tcp-simulator) | Modbus TCP server for testing HMIs and SCADA without hardware |
| [dxf-part-calculator](https://github.com/softechies/dxf-part-calculator) | Cut length, pierces, area and quotes from DXF files |
| [nextjs-supabase-saas-starter](https://github.com/softechies/nextjs-supabase-saas-starter) | Multi tenant SaaS starter with RLS, roles, invites and licensing |
| [pk-courier-sdk](https://github.com/softechies/pk-courier-sdk) | TypeScript SDK for Leopards and PostEx |

**Tech:** C# · .NET · TypeScript · Next.js · React · Supabase · PostgreSQL · Flutter
